# Happy Study — DWB Serena Tunnel Setup

**by อ.คฑาวุฐ**

ตัวติดตั้งอัตโนมัติสำหรับ Windows เชื่อม **ChatGPT → OpenAI Secure MCP Tunnel → Serena → เครื่องของคุณ**
ออกแบบให้ผู้ใช้ที่ไม่มีพื้นฐานคอมพิวเตอร์ **กดปุ่มเดียวจบ**

---

## วิธีใช้

1. ดาวน์โหลดโฟลเดอร์นี้ หรือไฟล์ zip จาก [Releases](../../releases)
2. คัดลอก `.env.example` เป็น `.env` แล้วใส่ OpenAI API Key กับ Tunnel ID ของคุณ
3. ดับเบิลคลิก **`Run-Setup.bat`**
4. กดปุ่มเขียว **"เริ่มติดตั้งอัตโนมัติ"**

ครั้งแรกใช้เวลาประมาณ 3–10 นาที เพราะต้องดาวน์โหลด Python และ Serena

## ระบบทำอะไรให้บ้าง

| ขั้น | รายละเอียด |
|---|---|
| 1 | เตรียมโฟลเดอร์ติดตั้ง |
| 2 | ตรวจและติดตั้ง `uv` |
| 3 | ตรวจและติดตั้ง Python 3.13 |
| 4 | ตรวจและติดตั้ง Serena |
| 5 | ติดตั้ง OpenAI tunnel-client (ดาวน์โหลดอัตโนมัติได้) |
| 6 | บันทึก Tunnel ID และเข้ารหัส API Key ด้วย Windows DPAPI |
| 7 | สร้างไฟล์เริ่มใช้งานและ Shortcut บน Desktop |
| 8 | เปิด Tunnel และทดสอบการเชื่อมต่อ |

## ดาวน์โหลด tunnel-client อัตโนมัติ

ถ้าไม่มีโฟลเดอร์ `tunnel-client` อยู่ในชุดติดตั้ง ตัวติดตั้งจะดาวน์โหลดให้เองจากลิงก์ใน `.env`

```
tunnel client url : https://github.com/romeofiles007-arch/happy-study-serena-setup/releases/download/v1.0.0/tunnel-client.zip
```

ดาวน์โหลดครั้งเดียว เก็บไว้ที่ `%LOCALAPPDATA%\Happy Study\cache` ครั้งต่อไปใช้ของเดิม
รองรับลิงก์จาก GitHub Releases, Google Drive, Dropbox และ Hugging Face โดยแปลงเป็น direct download ให้อัตโนมัติ

## ถอนการติดตั้ง

ดับเบิลคลิก **`Run-Uninstall.bat`** เลือกได้ว่าจะลบอะไร แบ่งเป็น 3 ระดับ

- **กลุ่ม 1** เฉพาะโปรแกรมนี้ — ติ๊กไว้ให้แล้ว ปลอดภัย
- **กลุ่ม 2** ถอน Serena / Python 3.13 / uv — สำหรับทดสอบติดตั้งใหม่ตั้งแต่ศูนย์
- **กลุ่ม 3** ลบ `.serena` ทั้งโฟลเดอร์ — อันตราย ปกติไม่ต้องติ๊ก

ตัวถอนจะตรวจก่อนว่าโฟลเดอร์เป็นของโปรแกรมนี้จริง และลบเฉพาะ `uv.exe` / `uvx.exe` / `uvw.exe` ไม่แตะไฟล์อื่นในโฟลเดอร์เดียวกัน

## หลังติดตั้งเสร็จ

- เปิดใช้งานครั้งต่อไปจาก Shortcut บน Desktop
- **หน้าต่างสีดำต้องเปิดค้างไว้** ตลอดเวลาที่ใช้ ChatGPT ปิดเมื่อไหร่ = ตัดการเชื่อมต่อ
- ตรวจสถานะได้ที่ <http://127.0.0.1:18010/ui>

## ความปลอดภัย

- API Key ในโฟลเดอร์ติดตั้งถูกเข้ารหัสด้วย **Windows DPAPI** ผูกกับ Windows user ที่ติดตั้งเท่านั้น
- ไฟล์ `.env` **ไม่ถูก commit** ขึ้น repo นี้ (อยู่ใน `.gitignore`)
- ถ้าจะแจกให้ผู้อื่น ควรให้แต่ละคนใช้ API Key ของตัวเอง

## ความต้องการของระบบ

- Windows 10 / 11
- Windows PowerShell 5.1 (มีมาให้อยู่แล้ว)
- ต้องต่ออินเทอร์เน็ตระหว่างติดตั้ง
