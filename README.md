## วิธีใช้

1. กดลิงก์ดาวน์โหลดข้างบน
2. คลิกขวาที่ไฟล์ zip → **Extract All** → Extract
3. เข้าโฟลเดอร์ `HappyStudy-Setup` → `Setup` แล้วดับเบิลคลิก **`Run-Setup.bat`**
4. กด **"แก้ไข"** วาง OpenAI API Key กับ Tunnel ID ที่ได้รับมา แล้วกดบันทึก
5. กดปุ่มเขียว **"เริ่มติดตั้งอัตโนมัติ"**

ครั้งแรกใช้เวลาประมาณ 3–10 นาที เพราะต้องดาวน์โหลด Python และ Serena

> ถ้าคีย์ถูกใส่มาให้แล้ว ข้ามข้อ 4 ได้เลย หน้าจอจะขึ้น **✓ พร้อมติดตั้ง**

## ดาวน์โหลด tunnel-client อัตโนมัติ

ถ้าไม่มีโฟลเดอร์ `tunnel-client` อยู่ในชุดติดตั้ง ตัวติดตั้งจะดาวน์โหลดให้เองจากลิงก์ใน `.env`

```
tunnel client url : https://github.com/romeofiles007-arch/happy-study-serena-setup/releases/download/v1.0.0/tunnel-client.zip
```

ดาวน์โหลดครั้งเดียว เก็บไว้ที่ `%LOCALAPPDATA%\Happy Study\cache` ครั้งต่อไปใช้ของเดิม
รองรับลิงก์จาก GitHub Releases, Google Drive, Dropbox และ Hugging Face โดยแปลงเป็น direct download ให้อัตโนมัติ

## ถอนการติดตั้ง

ดับเบิลคลิก **`Run-Uninstall.bat`** เลือกได้ว่าจะลบอะไร แบ่งเป็น 3 ระดับ

- **กลุ่ม 1** เฉพาะโปรแกรมนี้ — ติ๊กไว้ให้แล้ว ปลอดภัย
- **กลุ่ม 2** ถอน Serena / Python 3.13 / uv — สำหรับทดสอบติดตั้งใหม่ตั้งแต่ศูนย์
- **กลุ่ม 3** ลบ `.serena` ทั้งโฟลเดอร์ — อันตราย ปกติไม่ต้องติ๊ก

ตัวถอนจะตรวจก่อนว่าโฟลเดอร์เป็นของโปรแกรมนี้จริง และลบเฉพาะ `uv.exe` / `uvx.exe` / `uvw.exe` ไม่แตะไฟล์อื่นในโฟลเดอร์เดียวกัน

## หลังติดตั้งเสร็จ

- เปิดใช้งานครั้งต่อไปจาก Shortcut บน Desktop
- **หน้าต่างสีดำต้องเปิดค้างไว้** ตลอดเวลาที่ใช้ ChatGPT ปิดเมื่อไหร่ = ตัดการเชื่อมต่อ
- ตรวจสถานะได้ที่ <http://127.0.0.1:18010/ui>

## เวลาสั่งงานผ่าน ChatGPT

ทุกคำสั่งที่สั่งผ่าน tunnel มีเพดานเวลาราว **143 วินาที** ถ้าเกิน ฝั่ง OpenAI จะตัดการเชื่อมต่อทิ้ง

ชุดนี้ตั้ง Serena ให้ยอมแพ้ที่ **90 วินาที** ซึ่งต่ำกว่าเพดาน ChatGPT จึงได้คำตอบว่า "หมดเวลา" แล้วหาทางอื่นต่อได้ แทนที่ระบบจะพังทั้งชุด
และถ้าการเชื่อมต่อหลุดจริง หน้าต่างสีดำจะเชื่อมต่อใหม่ให้เองภายใน 5 วินาที **ไม่ต้องปิดเปิดใหม่**

งานสามอย่างนี้ให้เปิด PowerShell อีกหน้าต่างทำเอง อย่าสั่งผ่าน ChatGPT

| งาน | ทำไม |
|---|---|
| ติดตั้งไลบรารีขนาดใหญ่ เช่น `pip install torch` | ไฟล์หลาย GB ใช้เวลาเกิน 90 วินาทีเสมอ |
| เปิดเซิร์ฟเวอร์ที่รันค้าง เช่น `python app.py --port 7860` | คำสั่งไม่มีวันจบ ค้างจนหมดเวลาแน่นอน |
| คำสั่งที่ต้องพิมพ์ตอบโต้ เช่น ใส่รหัสผ่าน | ตอบกลับผ่าน tunnel ไม่ได้ |

### ให้ Serena เปิดโปรเจกต์ให้อัตโนมัติ (ไม่บังคับ)

สร้างไฟล์ `config\project.txt` ในโฟลเดอร์ติดตั้ง ใส่ **ชื่อโปรเจกต์** ของ Serena บรรทัดเดียว เช่น `PersonaLive`

Serena จะเปิดโปรเจกต์นี้ให้ทุกครั้งที่เริ่มทำงาน ไม่ต้องสั่ง activate ใหม่หลังเชื่อมต่อใหม่
ใส่ **ชื่อโปรเจกต์** เท่านั้น ห้ามใส่ path เต็มหรือค่าที่มีช่องว่าง

## ความปลอดภัย

- API Key ในโฟลเดอร์ติดตั้งถูกเข้ารหัสด้วย **Windows DPAPI** ผูกกับ Windows user ที่ติดตั้งเท่านั้น
- ไฟล์ `.env` **ไม่ถูก commit** ขึ้น repo นี้ (อยู่ใน `.gitignore`)
- ถ้าจะแจกให้ผู้อื่น ควรให้แต่ละคนใช้ API Key ของตัวเอง

## ความต้องการของระบบ

- Windows 10 / 11
- Windows PowerShell 5.1 (มีมาให้อยู่แล้ว)
- ต้องต่ออินเทอร์เน็ตระหว่างติดตั้ง
