Happy Study - DWB Serena Tunnel Auto Setup
by อ.คฑาวุฐ

====================================================
วิธีใช้ (สำหรับผู้ใช้ทั่วไป)
====================================================

1. ดับเบิลคลิก  Run-Setup.bat
2. กดปุ่ม "เริ่มติดตั้งอัตโนมัติ"  (ปุ่มเขียวใหญ่)

จบแค่นี้ครับ

Tunnel ID และ OpenAI API Key ถูกเตรียมไว้ในไฟล์ .env ให้แล้ว
โปรแกรมจะอ่านให้อัตโนมัติ ไม่ต้องพิมพ์เอง
ถ้าต้องการเปลี่ยนค่า ให้กดคำว่า "แก้ไข" ที่มุมขวาของกล่องการตั้งค่า

ครั้งแรกอาจใช้เวลา 3-10 นาที เพราะต้องดาวน์โหลด Python และ Serena
ถ้าขึ้นข้อความ "กำลังดาวน์โหลด Python 3.13" ให้รอ อย่าเพิ่งปิด

====================================================
การคัดลอก / ส่งต่อให้คนอื่น
====================================================

วิธีที่แนะนำที่สุด: ใช้ไฟล์ Happy-Study-Setup.zip (ประมาณ 26 MB)
ส่งไฟล์เดียว แล้วคลิกขวา > Extract All ที่เครื่องปลายทาง
วิธีนี้ไม่มีทางคัดลอกตกหล่น

ถ้าไฟล์ ZIP มาจากการดาวน์โหลดหรือส่งผ่านเน็ต ก่อนแตกไฟล์ให้
คลิกขวาที่ ZIP > Properties > ติ๊ก Unblock > OK เสียก่อน

หรือจะคัดลอก "โฟลเดอร์ Setup" ทั้งโฟลเดอร์ไปเองก็ได้
แต่ต้องตรวจว่าขนาดรวมประมาณ 57 MB และมีโฟลเดอร์ tunnel-client ครบ
โฟลเดอร์นี้มีทุกอย่างครบในตัวแล้ว รวมถึง tunnel-client

  Setup\
      Run-Setup.bat                 <- ไฟล์ที่ต้องดับเบิลคลิก
      HappyStudy-SetupWizard.ps1
      .env                          <- Tunnel ID + API Key
      README.txt
      tunnel-client\
          tunnel-client.exe
          cloudflared.exe

ห้ามแยกไฟล์ออกจากกัน และห้ามคัดลอกไปแค่บางไฟล์
ถ้าขาดโฟลเดอร์ tunnel-client จะติดตั้งไม่ได้

หมายเหตุ: ชุดนี้ไม่ได้ดาวน์โหลด tunnel-client จากอินเทอร์เน็ต
แต่ใช้ไฟล์ที่แนบมาในโฟลเดอร์ tunnel-client

====================================================
ระบบจะทำให้อัตโนมัติ
====================================================

- ตรวจและติดตั้ง uv (ถ้ายังไม่มี)
- ตรวจและติดตั้ง Python 3.13 (ถ้ายังไม่มี)
- ตรวจและติดตั้ง Serena
- ติดตั้ง OpenAI tunnel-client จากชุดติดตั้ง
- บันทึก Tunnel ID
- เข้ารหัส API Key ด้วย Windows DPAPI
- สร้าง Shortcut บน Desktop
- เปิด Tunnel และทดสอบการเชื่อมต่อ
- ถ้าทดสอบผ่าน จะเปิดหน้าทดสอบใน Browser ให้อัตโนมัติ

====================================================
หลังติดตั้งเสร็จ
====================================================

- เปิดใช้งานครั้งต่อไป: ดับเบิลคลิก Shortcut บน Desktop
  ชื่อ "Happy Study - DWB Serena Tunnel"

- หน้าต่างสีดำที่เปิดขึ้นมา ต้องเปิดค้างไว้ตลอดเวลาที่ใช้ ChatGPT
  ถ้าปิดหน้าต่าง = ตัดการเชื่อมต่อทันที

- หน้าตรวจสอบสถานะ: http://127.0.0.1:18010/ui

====================================================
ถ้ามีปัญหา
====================================================

- ต้องเชื่อมต่ออินเทอร์เน็ตระหว่างติดตั้ง
- ถ้าหน้าต่างสีดำขึ้นข้อความสีแดง ให้ถ่ายรูปหน้าจอส่งให้ผู้ดูแลระบบ
  หน้าต่างจะค้างไว้ให้อ่านเสมอ ไม่ปิดหนีเอง
- ถ้าขึ้นว่าพอร์ต 18010 ถูกใช้งานอยู่ แปลว่ามี Tunnel เปิดค้างอยู่แล้ว
  ไม่ใช่ปัญหา ปิดหน้าต่าง Tunnel เดิมก่อนถ้าต้องการเริ่มใหม่
- หน้าต่างติดตั้งจะบอกทุกขั้นตอนว่าผ่านหรือไม่ผ่าน
  ถ้าไม่ผ่าน จะบอกด้วยว่าติดที่ขั้นไหนและเพราะอะไร

====================================================
เรื่องความปลอดภัย
====================================================

- API Key ในโฟลเดอร์ติดตั้ง จะถูกเข้ารหัสด้วย Windows DPAPI
  ผูกกับ Windows user ที่ติดตั้งเท่านั้น คนอื่นเปิดอ่านไม่ได้

- แต่ไฟล์ .env ในชุดติดตั้งนี้ยังเก็บ API Key เป็นข้อความธรรมดา
  ใครได้ไฟล์ชุดนี้ไป จะเห็น API Key ทันที
  ก่อนแจกจ่ายให้ผู้อื่น ควรพิจารณาให้แต่ละคนใช้ Key ของตัวเอง
====================================================
ถอนการติดตั้ง / ล้างเครื่องเพื่อทดสอบใหม่
====================================================

ดับเบิลคลิก  Run-Uninstall.bat

จะมีหน้าต่างให้ติ๊กเลือกว่าจะลบอะไรบ้าง แบ่งเป็น 3 กลุ่ม

กลุ่ม 1 - เฉพาะโปรแกรมนี้ (ติ๊กไว้ให้แล้ว ปลอดภัย)
   - หยุด tunnel-client / serena ที่กำลังทำงาน
   - ลบโฟลเดอร์ที่ติดตั้งไว้
   - ลบ Shortcut บน Desktop
   - ลบไฟล์ตั้งค่า happy-study-serena.yaml

กลุ่ม 2 - สำหรับทดสอบติดตั้งใหม่ตั้งแต่ศูนย์ (ต้องติ๊กเอง)
   - ถอน Serena ออกจาก uv
   - ถอน Python 3.13 ที่ uv ติดตั้ง (เวอร์ชันอื่นไม่ถูกแตะ)
   - ถอน uv ทั้งหมด

   ติ๊กครบ 3 ข้อนี้ = เครื่องกลับไปเหมือนยังไม่เคยติดตั้งอะไรเลย
   เหมาะกับการทดสอบว่า Run-Setup.bat ทำงานได้จริงบนเครื่องเปล่า

กลุ่ม 3 - อันตราย (ปกติไม่ต้องติ๊ก)
   - ลบโฟลเดอร์ .serena ทั้งหมด
     มี projects, memories และ language servers อยู่ข้างใน
     การทดสอบติดตั้งใหม่ไม่จำเป็นต้องลบส่วนนี้

ความปลอดภัย
- ตัวถอนจะตรวจก่อนว่าโฟลเดอร์ที่จะลบเป็นของโปรแกรมนี้จริง
  ถ้าเลือกโฟลเดอร์ผิด จะปฏิเสธและไม่ลบให้
- claude.exe (Claude Code) อยู่ในโฟลเดอร์เดียวกับ uv
  ตัวถอนลบเฉพาะ uv.exe / uvx.exe / uvw.exe เท่านั้น ไม่ลบทั้งโฟลเดอร์
- ถ้าลบโฟลเดอร์ไม่ได้เพราะมีโปรแกรมเปิดค้าง จะบอกวิธีแก้ในกล่องข้อความ
